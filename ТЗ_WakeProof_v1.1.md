## 1. Общие сведения

### 1.1. Идентификация проекта

| Параметр | Значение |
|---|---|
| Название приложения | WakeProof |
| Пакет | com.wakeproof.alarm |
| Платформа | Android |
| minSdk | 28 (Android 9) |
| targetSdk | Последний стабильный на момент сборки |
| Язык интерфейса | Русский (английский — v2.0) |
| Язык кода | Kotlin (имена, комментарии, README — на английском) |

### 1.2. Назначение

Будильник, который нельзя выключить, пока пользователь не докажет, что проснулся, решив задачи. Вторая половина идеи: **не дать уснуть обратно** — после выключения через N минут проходит тихая контрольная проверка. Опционально: привязка к физической QR/NFC-метке, адаптивная сложность, запись шумов сна с возможностью «избранного».

### 1.3. Целевая аудитория

Люди, которые просыпают обычные будильники, ненавидят культуру «отложить на 5 минут», выключают будильник полусонным и засыпают обратно, а также хотят понять, что происходит с ними ночью.

### 1.4. Ключевые принципы

1. Никакой рекламы на экране звонка, задачи или в foreground service. Никогда.
2. Вся логика и данные — только на устройстве. Никакого облачного бэкенда, никаких загрузок аудио или статистики.
3. Одно основное действие на экран во время звонка. Никаких меню, настроек, навигации.
4. Безопасность важнее хардкора. Аварийный выход существует, неудобен, но никогда не приводит к тупику.
5. Скучные идиоматичные решения Android вместо «умных» абстракций.

### 1.5. Глоссарий (новое в v1.1)

| Термин | Значение |
|---|---|
| Задача | Полный блок одного типа («Математика», «Память», «Stroop»). Состоит из нескольких ответов. |
| Ответ (раунд) | Один шаг внутри задачи: один пример, одна последовательность, один раунд Stroop. |
| Сессия звонка | От срабатывания будильника до его выключения (или аварийного выхода). |
| Контрольная проверка | Тихий повторный звонок через N минут после выключения будильника (раздел 4.3). |
| Чистое утро | Будильник выключен решением задач: без snooze, без аварийного выхода, без пропуска; контрольная проверка (если включена) пройдена без повторного полного звонка. |
| Серия (streak) | Число подряд идущих чистых утр (раздел 4.4). |
| Фрагмент | Сохранённый на диск аудиофайл со значимым ночным звуком. |
| Избранное | Фрагмент, помеченный пользователем звёздочкой; исключается из автоочистки (раздел 4.7). |

## 3. Разрешения

| Разрешение | Назначение | Когда запрашивается |

| SCHEDULE_EXACT_ALARM | Резерв, если USE_EXACT_ALARM недоступен/отозван | Рантайм: только если canScheduleExactAlarms() == false — отправка пользователя в спец. настройки при первом создании будильника |

| POST_NOTIFICATIONS | Уведомления сервисов | При первом запуске (Android 13+) |
| RECEIVE_BOOT_COMPLETED | Перепланирование после перезагрузки | Автоматически (manifest) |
| RECORD_AUDIO | Запись сна | Только при включении «Режима сна» (включая плитку и напоминание) |
| FOREGROUND_SERVICE_MEDIA_PLAYBACK | Сервис звонка (Android 14+) | Автоматически (manifest) |
| FOREGROUND_SERVICE_MICROPHONE | Сервис записи (Android 14+) | Автоматически (manifest) |
| CAMERA | QR-якорь | Только при выборе QR для будильника; сам скан при звонке — без повторного запроса |
| NFC | NFC-якорь | Автоматически (manifest) |
| REQUEST_IGNORE_BATTERY_OPTIMIZATIONS (опционально) | Стабильная запись ночью | **Только вручную** из настроек, с экраном-объяснением; никаких автоматических запросов |

**Отказ от DND-доступа (изменение v1.1).** Отдельное разрешение на «Не беспокоить» не запрашивается: звук играет через AudioAttributes.USAGE_ALARM и слышен в DND при стандартной системной галке «Будильники». Если пользователь отключил будильники в DND — в настройках приложения показывается подсказка.

## 4. Функциональные требования

### 4.1. Ядро будильника (P0)

#### 4.1.1. Список и редактор будильников

Создание, редактирование, удаление будильников. Хранение в Room. Перепланирование всех включённых будильников после загрузки устройства и смены времени/часового пояса.

Поля будильника:

| Поле | Значения | По умолчанию |
|---|---|---|
| Время, дни недели, вкл/выкл | — | — |
| Типы задач | Мультивыбор: математика / память / Stroop | математика + Stroop |
| Режим сложности | Лёгкий / средний / хардкор (адаптивный — с v1.1, раздел 4.5) | средний |
| Политика snooze | Запрещён / один раз / один раз с усложнением | запрещён |
| Нарастание громкости | Вкл/выкл | вкл |
| Контрольная проверка | Вкл/выкл + интервал 5/10/15 мин (раздел 4.3) | вкл, 10 мин |
| QR/NFC-якорь | Опционально: выбрать метку | выкл |
| Напоминание ко сну | Вкл/выкл + целевая длительность сна (раздел 4.8) | вкл, 8 ч |

#### 4.1.2. Политика snooze

- По умолчанию запрещён. Кнопки snooze на экране звонка нет.
- **«Один раз»** — snooze без последствий: повторный звонок с теми же параметрами.
- **«Один раз с усложнением»** — snooze с последействием.
- Интервал snooze — **10 минут** (константа). Лимит «один раз» действует на одно срабатывание будильника.
- Правило усложнения (только для «с усложнением»): к повторному звонку добавляется **+1 задача** (максимум 4 задачи за сессию). Если задач уже 4 — режим сложности повышается на один уровень (лёгкий → средний → хардкор; выше хардкора нет).
- В хардкоре snooze недоступен всегда — настройка snooze игнорируется.

#### 4.1.3. Экран звонка

- Полноэкранный, поверх блокировки. Показывает время и одну задачу за раз.
- Не закрывается свайпом. Кнопка Back отключена.
- Уход из приложения → foreground service возвращает экран в течение 2 секунд и **ускоряет нарастание громкости до максимума** (если громкость ещё не максимальна — см. 4.1.5).
- После решения нужного числа задач — остановка будильника, короткая сводка и включение контрольной проверки (раздел 4.3), если она задана:

```
☀️ Доброе утро!
⏱ Задачи: 1:42 · ошибок: 1
🔥 Серия: 12 утр
✅ Контрольный звонок через 10 мин  [Отменить (1 задача)]
```

- Никакой рекламы, промо и апселлов на этом экране. Никогда.

#### 4.1.4. Аварийный выход

- Скрытая маленькая область на экране звонка. Активация: долгое нажатие 5 секунд → экран выхода.
- **Фраза выхода** из 4 слов генерируется один раз при первом запуске (локальный словарь ~200 слов, в v1.0 — русский) и хранится локально. Посмотреть и перегенерировать: Настройки → «Аварийный выход».
- На экране выхода: поле ввода + **сама фраза мелким серым шрифтом** в качестве подсказки. Принцип: неудобно (набрать 4 слова сонному), но тупика нет никогда (см. 1.4, п. 4).
- Событие логируется в Room: время, будильник, сколько задач решено до выхода, длительность сессии. Сама фраза не логируется.
- Предназначен только для экстренных случаев.

#### 4.1.5. Постепенное нарастание громкости

- Настраивается для каждого будильника. По умолчанию — включено.
- Кривая: от 20% до 100% за 60 секунд, линейно (шаг 5% каждые 3 с), вибрация синхронно.
- Если нарастание выключено — громкость 100% с первой секунды.
- Если задача не решена — громкость достигает 100% и остаётся там до конца сессии. События «увеличить громкость» (см. 4.1.3) влияют только на скорость роста, не выше 100%.

### 4.2. Задачи для выключения (P0)

#### 4.2.1. Типы задач и параметры по режимам сложности

**Математика.** Простая арифметика (сложение, вычитание, умножение), целочисленный ответ, генерация в рантайме. Требуется N правильных ответов подряд (сброс streak внутри задачи при ошибке). Возвращает TaskResult(timeTakenMs, mistakes, taskType).

**Память.** Последовательность цветных кнопок (вспышка по очереди), пользователь повторяет. Длина зависит от сложности.

**Stroop.** Название цвета, напечатанное другим цветом чернил; нажать на цвет чернил, а не на слово. N раундов подряд.

| Параметр | Лёгкий | Средний | Хардкор |
|---|---|---|---|
| Математика: ответов подряд | 2 | 3 | 5 |
| Математика: операнды | до 20 | до 99 | до 999; умножение до 30×30 |
| Память: длина последовательности | 4 | 5 | 6 |
| Stroop: раундов | 3 | 5 | 7 |

**Определение «хардкор» (уточнение v1.1):** 4 задачи, snooze принудительно запрещён, нарастание громкости отключено (максимальная громкость сразу), контрольную проверку нельзя отключить (можно менять только интервал).

**QR/NFC-якорь (опционально для каждого будильника).** Если включён — после когнитивных задач пользователь обязан отсканировать зарегистрированный QR-код или приложить NFC-метку. Идентификатор хранится локально (Room). Якорь не входит в счётчик когнитивных задач и идёт всегда последним.

#### 4.2.2. Количество задач

- Настраивается для каждого будильника: 1–4 когнитивные задачи.
- По умолчанию — 2 задачи разных типов (например, математика + Stroop).
- Если задач больше, чем выбрано типов, — типы повторяются по кругу, подряд один и тот же тип не идёт.
- Итоговое число задач сессии = настроенное количество + 1 (snooze с усложнением) + 1 (низкий балл адаптива, v1.1). Максимум 4; дальше — повышение уровня сложности (см. 4.1.2, 4.5.2).

#### 4.2.3. QR/NFC-якорь: сценарий деградации (новое в v1.1)

- Экран скана: предпросмотр камеры + **кнопка фонарика (включён по умолчанию)** — скан происходит в тёмной спальне.
- Если за 3 минуты (или после 5 неудачных попыток) якорь не считан — экран «Метка недоступна?» с выбором:
  - «Попробовать ещё» — таймер продлевается;
  - «Заменить задачами» — 2 дополнительные когнитивные задачи вместо якоря, в сессию пишется отметка «якорь пропущен»;
  - «Аварийный выход» — штатный сценарий 4.1.4.

### 4.3. Контрольная проверка — «Проверка через 10 минут» (НОВОЕ, P0)

Решает проблему «выключил будильник и уснул обратно через минуту».

- После успешного выключения будильника автоматически ставится **один контрольный звонок через N минут** (по умолчанию 10; настройка 5/10/15 на будильник; по умолчанию включена).
- Контрольный звонок: тихий (30% громкости, без нарастания, короткий сигнал), экран с **одной лёгкой задачей** (математика «лёгкий», 1 ответ).
- Успех → утро окончено. В сессию пишется «проверка пройдена с 1-й попытки».
- На решение даётся 60 секунд. Игнор или провал → **полный повторный звонок**: громкость 100%, +1 задача, snooze недоступен. Максимум 2 повторных звонка, дальше звонок звучит до решения (аварийный выход остаётся доступен всегда).
- Отменить проверку заранее можно только решением: в уведомлении «Контрольный звонок через 8 мин» кнопка «Отменить» открывает экран с 1 лёгкой задачей. Такая отмена засчитывается как пройденная (серия не страдает, в сессии пометка «отменена задачей»).
- Реализация: тот же механизм AlarmManager.setAlarmClock() + флаг recheck в Room; отдельный тихий звуковой паттерн.
- В хардкоре отключить проверку нельзя (только изменить интервал).

### 4.4. Серия — streak (НОВОЕ, P0)

- Серия = число подряд идущих **чистых утр** (определение — в глоссарии 1.5). Считается по всем будильникам вместе; каждое срабатывание = одно утро.
- Серия растёт, если: будильник выключен решением задач, без snooze и аварийного выхода, будильник не пропущен, контрольная проверка (если включена) пройдена без повторного полного звонка или отменена решением задачи.
- Серия сбрасывается при: snooze, аварийном выходе, пропущенном будильнике (см. раздел 5), повторном полном звонке после проверки.
- Хранение: поле result в таблице сессий: clean / snoozed / emergency / missed / recheck_failed.
- Отображение: утренняя сводка («🔥 Серия: 12»), главный экран под ближайшим будильником, экран «Статистика» (текущая + рекордная).

### 4.5. Адаптивная сложность — Wakefulness Score (P1)

#### 4.5.1. Формула (уточнение v1.1)

Считается после первой задачи сессии по её TaskResult:

- t = время решения первой задачи; m = медиана времени задач **того же типа** за последние 7 дней.
- Если наблюдений этого типа < 3 — берётся медиана по всем типам. Если всего наблюдений < 3 (холодный старт) — **адаптив не применяется**, используется настроенное число задач.
- time_score = 100, если t ≤ m; иначе max(0, 100 − 50 × (t − m) / m).
- **score = max(0, time_score − 15 × количество ошибок)**. Диапазон 0–100.
- Низкий балл = score < 50.

#### 4.5.2. Действие при низком балле

- Будильник не завершается: добавляется **+1 задача другого типа** (сверх настроенного количества, максимум 4; если уже 4 — уровень сложности повышается на один).
- Громкость +20% (в пределах 100%).
- Если включён QR-якорь — требование сканирования остаётся в силе.

#### 4.5.3. Доступность и отображение

- Режим «адаптивный» в редакторе сложности доступен только с v1.1 (в v1.0 редактор показывает: лёгкий / средний / хардкор).
- История баллов хранится в Room; график за 7 дней на экране «Статистика». На экране звонка не отображается.

### 4.6. Запись сна — упрощённая версия (P1)

#### 4.6.1. Подход

- Умная запись на основе VAD (рекомендация: WebRTC VAD, PCM 16 кГц моно).
- Аудиопоток читается постоянно, на диск сохраняются только фрагменты со значимым звуком.
- Кольцевой буфер в памяти: **8 секунд до начала звука + 12 секунд после** (константы).
- Формат файлов: AAC (.m4a), 16 кГц, моно, 32 кбит/с. Каталог: filesDir/recordings.

#### 4.6.2. Что записывается

Все шумы, превысившие порог VAD. Без анализа и моделей распознавания в MVP — только факты.

#### 4.6.3. Утренний отчёт

Длительность ночи = от старта записи до срабатывания будильника (или ручной остановки). Отчёт показывается сразу после выключения будильника — до контрольной проверки (пользователь может снова уснуть).

```
🌙 Ночь: 7ч 12м (запись 23:40 → 6:52)
🔊 Фрагментов: 14 · ⭐ В избранном: 2

[▶️ 02:14 (0:12)]  ☆
[▶️ 03:40 (0:08)]  ☆
[▶️ 05:22 (0:15)]
...
```

Только факты: время, длительность, кнопка воспроизведения, звёздочка «в избранное». Никаких автоматических выводов — пользователь сам решает, что это было.

#### 4.6.4. Контроль пользователя

- Кнопка «Остановить запись» всегда доступна в шторке уведомлений (foreground-уведомление).
- Запись включается вручную вечером (напоминание и плитка — раздел 4.8), не автоматически.
- Если пользователь забыл включить запись — ночи в отчёте просто нет, это не ошибка.

### 4.7. Избранное фрагментов (НОВОЕ, P1)

- В карточке сна и в плеере у каждого фрагмента кнопка ☆; повторный тап снимает отметку.
- Помеченные фрагменты (is_favorite = true в Room) **исключаются из автоочистки и лимита объёма** (раздел 6) и не удаляются автоматически никогда.
- Экран «Сон» содержит две вкладки: **«Ночи»** (обычные карточки ночей) и **«Избранное»**.
- Вкладка «Избранное»: список карточек (дата ночи, время фрагмента, длительность), встроенный плеер (play/pause, прогресс), кнопки ☆ (снять) и 🗑 (удалить вручную с подтверждением).
- Снятие звёздочки возвращает фрагмент под правило автоочистки — об этом сообщается в подсказке при снятии.
- Лимита на избранное нет; вверху вкладки отображается суммарный объём избранных фрагментов.
- Прослушивание — только локально. Опционально (v1.1): кнопка «Сохранить копию» на карточке избранного — экспорт файла через SAF, пользователь сам выбирает куда.

### 4.8. Напоминание «Ложись спать» + плитка быстрого старта (НОВОЕ, P1)

#### 4.8.1. Напоминание ко сну

- Время напоминания = ближайший включённый будильник **минус целевая длительность сна** (по умолчанию 8 ч; настройка 6–9 ч на будильник; либо фиксированное время).
- Работает только если на завтра есть включённый будильник.
- Уведомление (отдельный канал «Напоминания»):

```
🌙 Через 8 ч будильник в 6:30. Ложись спать.
[Начать запись]  [Через 15 мин]  [Сегодня не надо]
```

- [Начать запись] запускает запись сна (разрешения запрашиваются, если ещё не выданы; при отказе запись не стартует, ничего не ломается). Если «Режим сна» выключен — уведомление без кнопки записи.
- Игнорирование → до 2 повторов с интервалом 15 минут. «Сегодня не надо» — до следующего дня.

#### 4.8.2. Плитка Quick Settings «Запись сна»

- TileService в шторке быстрых настроек; без дополнительных разрешений.
- Тап — старт записи; повторный тап — остановка с сохранением сессии.
- Состояние плитки отражает состояние сервиса записи (активна/неактивна).
- Если разрешения на микрофон не выданы — плитка открывает экран настройки записи сна.
- Плитка, кнопка в уведомлении-напоминании и запуск из приложения используют один и тот же сервис записи.

### 4.9. Экспорт статистики в CSV (НОВОЕ, P1)

- Кнопка «Экспорт CSV» на экране «Статистика»; выбор отчёта: «Утра» / «Фрагменты сна».
- Сохранение через SAF (ACTION_CREATE_DOCUMENT), пользователь сам выбирает место.
- Файлы: wakeproof_mornings_ГГГГ-ММ.csv / wakeproof_fragments_ГГГГ-ММ.csv. Кодировка UTF-8 с BOM, разделитель «;» (дружелюбно к Excel).
- Отчёт «Утра»: дата; будильник; время срабатывания; время выключения; длительность решения, с; ошибки; snooze (да/нет); аварийный выход (да/нет); балл Wakefulness; серия; результат контрольной проверки.
- Отчёт «Фрагменты»: дата; время; длительность, с; в избранном (да/нет).
- Только вручную. Никаких автоматических отправок.

### 4.10. Экран «Статистика»

- Текущая и рекордная серия (v1.0).
- График Wakefulness Score за 7 дней (v1.1).
- Последние ночи с количеством фрагментов и ссылкой на «Сон» (v1.1).
- Кнопка «Экспорт CSV» (v1.1).

## 5. Крайние случаи (новое в v1.1)

| Случай | Поведение |
|---|---|
| Два будильника на одну минуту | Звонит один (более ранний по времени срабатывания); второй звонит сразу после выключения первого, если его время уже наступило. Сводки отдельные. |
| Смена часового пояса / переход на зимнее-летнее время | Прием TIMEZONE_CHANGED / TIME_SET → перепланирование всех будильников по новым локальным правилам. |
| Телефон был выключен в момент будильника | После BOOT: если время будильника прошло менее 12 ч назад и он не звонил → уведомление «Будильник пропущен», сессия = missed, серия сбрасывается. |
| Телефонный разговор во время звонка | Звук продолжает играть через USAGE_ALARM; вибрация отключается на время разговора. |
| Звонок во время записи сна | Запись не прерывается; фрагменты за время звонка сохраняются; утренний отчёт показывается после задач. |
| Разрешение микрофона отозвано во время записи | Сервис корректно останавливается, сессия сохраняется, уведомление «Запись остановлена». |
| Память заполнена | Сначала автоочистка по правилам раздела 6 (избранное не трогаем); если не помогло — запись останавливается с уведомлением. |
| Пользователь отключил будильники в DND | В настройках приложения показывается подсказка, куда зайти, чтобы вернуть звук будильников. |

## 6. Данные и хранение (новое в v1.1)

- Room-сущности: Alarm, TaskSession (result: clean / snoozed / emergency / missed / recheck_failed, время, ошибки, балл), ScoreEntry, RecordingSession, AudioFragment (путь, начало, длительность, isFavorite).
- **Политика хранения записей:** 14 дней по умолчанию (настройка 7 / 14 / 30), общий лимит 500 МБ (настройка 200 МБ – 2 ГБ). Очистка запускается при старте приложения и после утреннего отчёта; удаляются самые старые **не избранные** фрагменты.
- **Избранное не удаляется автоматически никогда** и не учитывается в лимите.
- Android Auto Backup: аудио и база Room исключаются из облачного бэкапа (backup rules). Всё покидает устройство только руками пользователя (CSV, экспорт фрагмента — через SAF).

---

## 7. Приватность

- Всё только на устройстве. Никаких автоматических загрузок.
- Экспорт — только вручную (CSV, копия избранного фрагмента — SAF).
- Фраза аварийного выхода не логируется и не покидает устройство.
- Утренний отчёт содержит только факты, без интерпретаций и «диагнозов».

## 8. Тесты (JUnit 5, domain)

Минимум 30 unit-тестов; обязательные сценарии:

1. Генераторы задач: все примеры решаемы, диапазоны соответствуют режиму сложности, подряд не повторяются.
2. Машина snooze: три политики, интервал, правило усложнения (+1 задача → лимит 4 → уровень выше), сброс лимита на срабатывание.
3. Контрольная проверка: планирование, отмена решением, провал → повторный звонок, лимит повторов.
4. Серия: начисление, все варианты сброса, пропущенный день.
5. Wakefulness Score: формула, порог 50, cold start (< 3 наблюдений), медиана по типу/всем типам.
6. Кольцевой буфер VAD: pre-roll 8 с, post-roll 12 с, границы файла.
7. Retention: очистка по дням и лимиту объёма; избранное не удаляется ни при каком сценарии.
